🎯 추천 흐름 (마우스)
1) 셀 위로 마우스 이동 → 자동 미리보기
2) 클릭 = 그 셀 잠금 (마우스 떨어져도 유지)
3) 휠 ↑↓ = 활성숫자 변경 (잠긴 위치 그대로)
4) 숫자패드 클릭 또는 1~9 키 = 입력
5) 같은 셀 다시 클릭 / 우클릭 = 잠금 해제
⌨️ 키보드
방향키 — 셀 이동
1~9 — 숫자 입력
Shift+1~9 — 수동 마커 토글 (자동 마커 모드와 무관)
마커 수동 모드: 그냥 1~9 또는 패드 클릭 = 노트 토글
0 / Backspace — 지우기
L / R — 같은 숫자 셀 사이 점프
M — 마커 cycle (OFF → 수동 → 4+ → 3+ → 전체)
I — 라인 힌트 / C — 색상 / B — 흑백
H — 정답 1칸 / N — 새 문제 / Ctrl+Z — 되돌리기
🖱️ 마우스
좌클릭 — 선택 + 잠금 토글
우클릭 — 잠금 풀기 / 빈 셀이면 지우기
휠 — 활성숫자 ±1 (9개 다 채워진 숫자는 건너뜀)
📱 모바일/터치
셀 탭 — 선택만(라인/색상 미리보기). 즉시 입력 X
given 셀 탭 — 그 숫자 활성화 (같은 숫자 셀 라인 표시)
숫자패드 1~9 탭 — 활성숫자 변경 + 빈 셀이면 입력
같은 셀 다시 탭 — 입력값 지움 (토글)
아래 지우기 / 마커 OFF/ON 버튼
🎮 게임패드
방향 — 셀 이동 / A — 입력 / B — 지우기
LB/RB — 같은 숫자 점프 / LT/RT — 활성숫자 ±1
SELECT — 마커 / START — 새 문제
💡 색상 힌트 의미
밝은녹색·깜빡임=정답(1후보) / 짙은녹=유력(2) / 회청=가능(3) / 빨강=어려움(4+)
화면 클릭 / ESC = 닫기
